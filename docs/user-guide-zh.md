# Cinema Studio 使用手册（小白从零开始版）

> 适用对象：第一次打开 Cinema Studio、不懂部署也不懂视频模型的创作者。
> 读完你应该能：建一个项目 → 写好剧本 → 准备角色 → 排好分镜 → 渲染镜头 → 剪成片 → 导出 MP4。
>
> 部署、密钥、RunPod 镜像等运维内容不在本手册里，请看 [README](../README.md) 和 [deploy-cloudflare.md](deploy-cloudflare.md)。

---

## 0. 一分钟看懂它是什么

Cinema Studio 是一个**在浏览器里拍 AI 短片的"摄制组"**。它把拍片拆成固定的六步，按顺序做：

```
1 简报与风格 → 2 剧本 → 3 元素(角色/场景/道具) → 4 分镜板(渲染镜头) → 5 成片精修 → 6 时间线(剪辑+导出)
   Brief & style   Script     Elements                Board                    Finals          Timeline
```

几个关键事实，先记住：

| 事实 | 对你意味着什么 |
| --- | --- |
| 视频由自建的 **MiniMax H3** 模型在 RunPod GPU 上生成，**一个镜头 = 一次生成**，每个镜头 5–15 秒，768p，自带声音 | 一部 60 秒的片子大约是 5–8 个镜头 |
| 有**两道人工审批**：剧本、分镜表都必须由你在网页上点"批准"，否则**什么都不会渲染** | 不用担心 AI 偷偷花钱 |
| **花钱的操作都会先报价**，你点"Confirm and spend（确认并花费）"才真正执行；每个项目还有**预算上限** | 预算到顶会被拒绝，不会超支 |
| 网站**本身没有画图模型**：角色参考图、首帧图需要你**上传**（或让会画图的 AI 帮你生成后导入） | 提前准备好角色图片 |
| "导演"可以是你自己订阅的 **Claude 或 Grok**，通过 MCP 连接器接进来帮你写剧本、排分镜 | 推荐新手让 AI 导演代劳，自己只负责审批和挑片 |

## 1. 认识界面（网站地图）

### 1.1 顶栏（每个页面都有）

从左到右：

- **H3 Cinema Studio** 品牌标：点它回到项目列表。
- **当前项目名**（在项目里时显示）。
- **GPU 状态胶囊**：`GPU off`（关）/ `GPU starting`（启动中）/ `GPU on`（运行中，旁边显示显卡型号和本次已花费）/ `no GPU`（暂时没有可用显卡）/ `GPU not set up`（管理员还没配置）。点它进入 Machine 页。
- 四个全局页面：
  - **Projects** —— 项目列表（首页 `/`）
  - **Library** —— 风格预设库（Styles）和 LoRA 库（LoRAs），所有项目共享
  - **Machine** —— GPU 机器的开关、费用、存储状态
  - **Connect** —— 把 Claude / Grok 接进来当导演的地址和步骤

### 1.2 项目内的左侧栏

进入任一项目后，左边有一条竖栏：

- **← All projects**：回项目列表。
- **Spent $x / $y**：已花费 / 预算上限，下面是进度条（超支变红）。
- **board N s · target M s**：分镜板上镜头总时长 vs 你设定的目标时长，相等时变绿。
- **六个步骤 1–6**：顺序就是工作顺序。`Script` 和 `Board` 旁边有小灯：
  - 灰 `empty` = 还没有；黄 `draft` = 草稿未批准；绿 `approved` = 已批准。
- 栏底：
  - 绿灯 **Ready to render** = 可以开始渲染了；
  - 否则显示卡住你的原因，例如 `No script yet`（还没剧本）、`Script not approved`（剧本未批准）、`No shots yet`（还没镜头）、`Shotlist not approved`（分镜表未批准）。
  - **Project settings**：项目设置（改名、改预算、导演权限、删除项目）。

> 手机上左栏会变成**屏幕底部的 6 个标签**，功能一样。

## 2. 开始之前：三件准备工作

1. **能打开网站**。管理员给你的地址（如 `https://studio.xxx.com`）。正式部署有 Cloudflare Access 登录，用你被授权的邮箱登录即可；本地开发模式（`AUTH_MODE=dev`）不需要登录。
2. **看一眼 Machine 页**（顶栏 → Machine）：
   - `Backends` 里 **RunPod** 和 **R2 storage** 都应该是绿色 `configured`。如果是黄色 `missing ...`，说明管理员还没配置好——你仍然可以写剧本、建角色、排分镜，只是**不能渲染**，请联系管理员。
   - `Image models` 显示 `off` 是正常的（网站不自带画图模型）。
3. **准备素材**：
   - 每个主要角色 1–3 张清晰的参考图（正面、侧面、表情），JPG/PNG/WebP。
   - 如果想让某个镜头从指定画面开始，准备一张 **16:9（最好 1344×768）** 的"首帧图"。
   - 可选：一首背景音乐（MP3/WAV）。

## 3. 选一种玩法

| | 玩法 A：AI 导演代劳（**推荐新手**） | 玩法 B：全部手动 |
| --- | --- | --- |
| 谁写剧本、建角色、排分镜 | 你的 Claude / Grok，通过 MCP 自动写进网站 | 你自己在网页上填 |
| 你做什么 | 聊天提需求 → 网页上**审批** → **挑选**满意的镜头 | 每个字段都自己填 |
| 难度 | 低 | 高（要懂分镜、镜头语言） |

两种玩法**可以混用**：AI 写完后，你随时可以在网页上改任何一项。下面先讲玩法 A 的连接步骤，然后按六步逐页讲解（两种玩法都适用）。

### 3.1 连接 AI 导演（玩法 A 必做，一次即可）

1. 顶栏点 **Connect**，复制 **MCP endpoint**（形如 `https://你的站点/mcp`）。
2. 在聊天客户端添加自定义连接器：
   - **Claude**：Settings → Connectors → Add custom connector → 粘贴地址 → 在弹出的同意页登录。
   - **Grok**：grok.com → Connectors → New Connector → Custom → 粘贴同一地址 → 登录。
3. 在聊天里说：**"开始一部新电影"**（或 "start a new film"），并告诉它：
   - 片子讲什么、给谁看；
   - **总时长**（例如 60 秒）；
   - **总预算**（美元）；
   - 要不要音乐、字幕；
   - 任何必须有 / 必须避免的东西。
4. AI 会自己读取"导演手册"，调用 `start_film` 创建项目。回到网站 **Projects** 页就能看到新项目。

> 小贴士：网站更新后如果 AI 说"找不到某个工具"，在聊天客户端里**删除并重新添加连接器**刷新工具列表。
> Connect 页的 **Show director guide / Copy guide** 可以查看/复制完整导演手册，粘贴进聊天项目的说明里（可选）。

## 4. 从零开始：六步做出第一部片子

### 第 0 步：创建项目（Projects 页）

> 用 AI 导演的话，它会帮你建好，跳过这步。

1. 打开首页 **Projects**。
2. **New project** 填片名（如 `雨夜追逐`），**Budget cap (USD)** 填预算上限（默认 50）。
3. 点 **Create**，下方出现项目卡片，点进去。

项目卡片上的三个小方块分别代表：已写简报 / 分镜已批准 / 已开始花钱。

---

### 第 1 步：简报与风格（1 Brief & style）

这一步决定"拍什么、多长、长什么样"。

**① Brief（简报）**
- **The film, in your own words**：用大白话写这部片，例如 *"60 秒雨夜霓虹追逐：Mara 奔跑、回头、消失在人群里。"*
- **Target running time (s)**：目标总时长（秒）。填完后下方会出现建议拆分，如 `Plan: 6 shots · 10 + 10 + ... s`。
- 点 **Save brief**。

**② Style preset（风格预设）**
- 点 **Choose a style**，从 16 种风格里挑一个（水墨、80 年代赛璐璐动画、移轴微缩、新闻纪录片、城市交响曲……每张卡片有中英文名和一句话介绍）。
- 点卡片后，下面的 Look 字段会被自动填好。

**③ Look（全片统一外观，每个镜头都会继承）**
- Genre and tone（类型与基调）、Palette（色调）、Camera（摄影机）、Lens（镜头）、Lighting（布光）、Constraints（负面约束，例如 `no on-screen text` 不要画面文字）。
- **Aspect ratio（画幅）**：**新手请选 16:9**。H3 经过验证的分辨率是 1344×768（16:9），其他比例未经充分测试。
- **LoRAs**：项目默认 LoRA。一般选管理员准备好的"加速 LoRA"（8 步），渲染更快更便宜；不懂就保持默认。
- 改完点 **Save look**。

---

### 第 2 步：剧本（2 Script）——第一道审批

**获得剧本的三种方式：**
- 玩法 A：AI 导演写好后自动保存为新版本（`save_script`）。
- 用其他 AI 写：点右上角 **Copy prompt pack**，会复制一段已经带上片名和 Look 的提示词，粘贴给任意聊天 AI，让它写剧本，再把结果粘回来。
- 自己写：直接在 **New version** 文本框里写。

**操作：**
1. 粘贴/写好剧本 → 点 **Save as vN**（保存为第 N 版）。
2. 左下 **Versions** 表格列出所有版本，点任一行在右侧预览。
3. 读一遍，满意就点右上角 **Approve vN**（批准第 N 版）。左栏 Script 的灯变绿。

> ⚠️ **每存一个新版本，都会回到草稿状态**，需要重新批准。只有**最新一版**被批准才算数。

---

### 第 3 步：元素（3 Elements）——角色、场景、道具

元素 = 片子里反复出现、需要"长得一样"的东西。分三类：**character（角色）/ location（场景）/ prop（道具）**。

1. 点右上角 **New element**，打开抽屉：
   - **Kind**：类型；**Name**：名字（如 `Mara`）。
   - **Visual description**：具体的外观描述——年龄、体型、发型、服装、材质、光线。越具体越稳定。
   - **Fixed features**：**绝对不能变/不能消失的细节**，写清楚在哪一侧，例如 `龙纹身 / 左前臂内侧`、`红色贝雷帽 / 头顶`。点 **Add feature** 可加多条（最多 8 条）。
   - 点 **Create**（之后修改点 **Save**）。
2. **上传参考图**：在抽屉的 **Reference images** 区点上传按钮。第一张会标为 **PRIMARY（主参考）**。
3. **标注视角**：给每张参考图选它展示的是哪个视角（正面 / 侧面 / 表情等），这样侧脸镜头会自动用侧面图。选好后保存。
4. 想在别的项目复用这个角色？点抽屉里的 **Promote to library**（复制到共享库），页面底部 **Library** 区会出现它，其他项目可以直接导入。

> 玩法 A：AI 会帮你创建所有元素并写好描述，但**图片通常需要你上传**（除非你的 AI 客户端自己能画图）。

---

### 第 4 步：分镜板（4 Board）——第二道审批 + 渲染

这是最核心的页面。上面是工具栏，下面按**场景（scene）**分组排列**镜头卡片（shot）**。

#### 4.1 排出分镜

- 玩法 A：AI 调用 `save_shotlist` 会一次性写好所有场景和镜头，包括每个镜头的剪辑衔接和摄影参数。
- 手动：
  1. 页面底部输入场景代号（如 `alley-chase`）→ **Add scene**。
  2. 在场景标题行点 **Add shot** 加镜头；用 ↑↓ 调整顺序；**Palette** 设定该场景的配色；**Delete** 删除场景。

#### 4.2 编辑一个镜头（点镜头卡片打开抽屉）

抽屉有四个标签：

**Edit（编辑）** —— 镜头内容：
- **Duration (s)**：5–15 秒。建议 8–12 秒。
- **Mode（生成模式）**，新手只需了解前三种：
  - `text`：纯文字生成。适合空镜、开场环境镜头。
  - `keyframe`：从一张**首帧图**开始动（可选再给一张尾帧图）。适合需要精确构图、连续动作。
  - `reference`：用**角色参考图**保持人物长相一致。适合每段戏的第一个有人物的镜头。
  - （`edit` 为高级用法，新手忽略。）
- **Link to earlier shots（与前面镜头的衔接）**：硬切 `Hard cut`（默认）、长镜头续接 `Continuous`、首尾桥接 `Bridge`、插入后返回 `Insert, then return`、正反打 `Shot / reverse shot`、匹配剪辑 `Match cut`、跳切 `Jump cut`、蒙太奇 `Montage beat`、循环 `Loop`。不懂就用 **Hard cut**。
  - 注意：衔接类镜头要等它的"锚点镜头"**选定了一条 take** 之后才能渲染。
- **Intent**：一句话说清这个镜头是干嘛的。
- **Beats（节拍）**：按时间段写动作，格式"开始状态 → 一个动作 → 结束状态"。各段要正好铺满整个时长。
- **Camera（运镜）**：只选**一种**运动（不动就选 `static`，否则模型会乱飘），设幅度和速度。
- **What moves（什么在动）**：至少一项——镜头、人物、焦点、光线……全静止的画面是"死镜头"。
- **构图**：Subject at（主体放在 38% 或 62% 线上）、Headroom、On screen (s)。
- **First frame shows / Last frame shows**：用文字写清首帧、尾帧画面里谁站在哪、朝哪看。
- **Dialogue（台词）**：说话人、原文、语言、语气。**建议少写或不写**（模型对清晰说话的支持尚未验证），可以把人声写到音效里，比如"轻声笑"。
- **Sound（声音）**：SFX 音效（写成具体事件，如"雨打铁皮屋顶"）、Ambience 环境声、Music（写 `N/A` 表示不要配乐）。
- **Characters / Location / Props**：勾选这个镜头用到的元素（角色、道具各最多 3 个）。
- **Prompt override**：直接替换整个提示词。**新手留空**，让编译器自动写。
- 改完点抽屉右上角 **Save**。

**Compile（编译预览）** —— 看系统最终发给模型的提示词、使用的工作流、步数、**预计花费**和 GPU 秒数。**花钱前强烈建议先看一眼。**

**Frames（画面）** —— 首帧/尾帧：
- **Hero frame（首帧）**：上传，或从本项目已有图片里挑（已完成的 take 会自动提供 `LAST FRAME` 尾帧图，可作为下一镜的首帧）。
- **End frame（尾帧，可选）**：上传，或点 **Derive end frame (push-in)** 从首帧自动裁出一张放大图作为尾帧，保证镜头一定会往前推。
- **Frame check**：用 Difference（差异）/ Onion skin（洋葱皮）对比首尾帧是否对得上。

**Takes（渲染结果）** —— 见 4.4。

#### 4.3 检查并批准分镜表

工具栏按钮（从左到右）：
- **Sketch**：根据分镜表自动画出**色块故事板**（镜头大小、构图、走位、配色），可切换 **Grayscale** 黑白检查主体是否突出。
- **Lint · N**：分镜体检。会指出节奏问题（没有喘息、连续 5 个同样的衔接、节拍没铺满）、缺失的摄影参数、以及 AI 视频容易翻车的画面（`fragile.*`）。**有错误先修。**
- **Apply style**：用你在第 1 步选的风格，自动填好每个镜头的摄影参数。
- **Approve shotlist**：批准分镜表。左栏 Board 灯变绿，栏底出现 **Ready to render**。

> ⚠️ 批准后再做**结构性修改**（增删镜头、改顺序等）会让分镜表**回到草稿**，需要重新批准。改 Note 之类的备注不会。

#### 4.4 渲染镜头（花钱的一步）

**推荐方式：批量渲染**
1. 分镜批准后，工具栏出现 **Render batch**，点它打开抽屉。
2. 抽屉列出所有还没有 take 的镜头、渲染顺序（系统会把 reference 模式的镜头排前面、锚点镜头排在衔接镜头前面）和**总估价**。
3. 先点 **Render probe (N)**：只渲染 1–2 个**最容易翻车**的镜头试水。
4. 弹出报价横幅 → 确认金额 → 点 **Confirm and spend**。
5. 试水镜头没问题，再点 **Render pass 1 (N)** 渲染第一轮（每个镜头一条 take）。有衔接关系的镜头会显示 `Waiting for an anchor`，等锚点镜头选定 take 后，再次打开 **Render batch** 渲染下一轮。

**单个镜头渲染**
1. 打开镜头抽屉 → **Takes** 标签。
2. **Takes**：一次生成几条（1–4，新手先 1 条）；**Steps**：留空（自动：有加速 LoRA 用 8 步，否则 20 步）。
3. 点 **Generate take** → 看报价 → **Confirm and spend**。

**渲染过程中**
- 第一次渲染时 GPU 会**自动开机**（顶栏胶囊变 `GPU starting` → `GPU on`），可能要等几分钟；空闲一段时间后**自动关机**省钱。
- take 状态依次为：`Waiting for the GPU pod`（等 GPU）→ 排队 → 运行中（有进度）→ 完成 / 失败。
- 显示 `no GPU` 表示允许使用的显卡暂时都没资源，稍后再试。

#### 4.5 挑选 take

每条完成的 take 下面有：
- 缩略图和视频；**Download** 下载。
- ⭐ 打分 + **Review notes** 备注 → **Save review**。
- **What went wrong**：勾选具体问题（会进入项目复盘）；**Sound unusable** 勾上后时间线会把这条的原声静音。
- **Use this take**：**选定这条作为该镜头的正式版本**。每个镜头都要选一条，后面的步骤才能用。
- 失败/超时的 take 有 **Retry**；运行中的可以 **Cancel**。

**take 不满意怎么办？按这个顺序考虑（省钱）：**
1. 问题只在开头或结尾几帧？→ 剪辑时裁掉就行（第 6 步的 In/Out）。
2. 时间线能救吗？→ 调速、静音原声。
3. 都不行 → 去 Edit 标签**改文字描述或换首帧**，再生成。**原样重跑通常会以同样方式失败。**
4. 同一个镜头试了 3 次还不行 → 换个拍法（改模式、拆镜头、简化动作）。

> 不要删掉没选中的 take，它们以后可能还能当插入镜头用。

---

### 第 5 步：成片精修（5 Finals）——可选，花钱

把每个镜头选中的 768p 版本**重新生成为高分辨率**（Open-H3-Regenerate-2K）。

- 表格列出每个镜头：选中的 take、高清版本状态、花费、评分。
- 顶部选分辨率 **1080p / 2K / 4K**，勾选 **close to the draft**（更贴近原片，适合有人物脸部的镜头），点 **Regenerate N picks at 2K** 批量精修；也可以单个点 **Regenerate 2K**。同样会先报价。
- **Blind comparison（盲测）**：同一镜头的两条 take 随机左右放，你选 **A is better / B is better / Tie** → **Submit vote**，帮你客观挑片。

> 新手建议：先用 768p 剪出完整片子满意了，再来这一步。

---

### 第 6 步：时间线（6 Timeline）——剪辑与导出

1. 点 **Auto build**：自动按分镜顺序，把每个镜头**选中的 take** 排成时间线。
2. 逐个片段调整：
   - **In (s) / Out (s)**：入点 / 出点，裁掉开头结尾不好的部分。
   - **Transition in**：转场方式和长度。
   - ↑↓ 调顺序，可删除片段。
   - 改完点右上角 **Save timeline**。
3. **Rough cut preview**：在网页里直接预览粗剪（只有硬切；溶解、音乐、字幕只在导出的文件里出现）。
4. **Beat grid（节拍网格，可选）**：填 BPM、每小节拍数、在哪一拍上切 → **Snap cuts to grid**，让剪辑点卡在音乐节拍上。
5. **Audio mix（混音）**：**Upload music** 上传背景音乐并选中，用滑块调各轨音量（dB）。
6. **Subtitles（字幕，可选）**：**Check subtitles** 检查每行字幕是否有足够阅读时间，可 **Show SRT / Copy SRT**。
7. **Export（导出）**：选择 **Preset**：

   | 预设 | 用途 |
   | --- | --- |
   | `preview-480p` | 低清快速预览，最便宜，先用它看整体 |
   | `master-768p` | 正式版，768p |
   | `master-upscaled` | 使用第 5 步生成的 2K 文件；没精修过的镜头会退回 768p 并提示 |
   | `social-9x16` | 竖屏社交媒体版 |

   需要的话勾 **Burn in subtitles**（字幕烧进画面），点 **Export**。
8. 下方 **Exports** 表格显示导出进度，完成后可下载成片。🎬

## 5. 关于钱：你需要知道的全部

- **哪些操作花钱**：生成 take、2K 精修、导出。写剧本、建元素、排分镜、编译预览、Lint、Sketch **都免费**。
- **先报价后执行**：所有花钱操作第一次点击只会弹出报价横幅，必须点 **Confirm and spend** 才会执行。
- **预算上限**：左栏 `Spent` 显示花费。预留金额会超过上限时操作会被拒绝（`budget_exceeded`）。在 **Project settings → Budget cap** 可以调整——这只有你能改，AI 导演永远不会自己加预算。
- **GPU 计费**：GPU 开着就在计费。第一次渲染自动开机，空闲后自动关机；也可以在 **Machine** 页手动 **Stop**。
- **省钱技巧**：
  - 先每镜 1 条 take、默认步数（8 步）做"预演"，满意了再精修。
  - 先 **Render probe** 试最难的镜头。
  - 花钱前看 **Compile** 标签的预估。
  - 预算快用完时，先导出 `preview-480p` 看看已有的部分。

## 6. 项目设置（Project settings）里的"导演"面板

左栏底部 **Project settings**：

- **Project name / Budget cap (USD)** → **Save**。
- **Director（导演面板）**：
  - **Spend envelope（授权额度）**：给 AI 导演一笔额度（美元）和有效时长（小时），点 **Grant**。在额度内，AI 可以不问你直接渲染**已通过审稿**的镜头；随时 **Revoke** 收回。新手可以不开。
  - **Delegated approval（委托审批）**：默认关闭。勾选后允许 AI 代你批准剧本 / 分镜表（仍有审稿和 Lint 的硬性条件，且每次都会记录）。**新手建议保持关闭，自己审批。**
  - **Requirements**：AI 记录下的你的每一条要求，可标记 **Met（已满足）/ Drop（放弃）/ Reopen（重开）**。
  - **Decisions**：AI 做的每个判断都记在这里，不同意就点 **Overturn（推翻）** 并写原因，AI 会读到。
  - **Reviews**：独立审稿人对剧本、每个镜头、成片的审查结果。
  - **Retro (Markdown)**：项目复盘——哪里出错、哪些写法修好了，供下一部片参考。
- **Danger zone → Delete project**：删除整个项目，**不可恢复**。

## 7. 常见提示与解决办法

| 你看到的 | 意思 | 怎么办 |
| --- | --- | --- |
| 左栏底部 `No script yet` / `Script not approved` | 没剧本 / 剧本没批准 | 去 **2 Script** 保存并点 **Approve** |
| `No shots yet` / `Shotlist not approved` | 没镜头 / 分镜没批准 | 去 **4 Board** 加镜头并点 **Approve shotlist** |
| 错误代码 `not_approved` | 审批没过就想渲染 | 横幅里会给出要去的页面链接 |
| 蓝色横幅带估价 + **Confirm and spend** | `needs_confirm`，等你确认花钱 | 确认金额后点按钮 |
| `budget_exceeded` | 会超过预算上限 | 去 Project settings 提高上限，或减少渲染 |
| 顶栏 `no GPU` | 允许的显卡暂时都没资源 | 等几分钟再试 |
| 顶栏 `GPU not set up` / Machine 页黄灯 `missing RUNPOD_*` | 管理员没配置 GPU | 联系管理员；期间可以先做剧本和分镜 |
| take 一直 `Waiting for the GPU pod` | GPU 正在开机 | 首次开机需要几分钟，耐心等 |
| take `failed` / `timeout` | 生成失败 | 点 **Retry**；多次失败联系管理员看 Machine 页 |
| 改完分镜灯又变黄 | 结构修改让分镜回到草稿 | 重新点 **Approve shotlist** |
| AI 说找不到 `cinematography` / `link` 字段或某个工具 | 连接器工具列表过期 | 在聊天客户端删除并重新添加连接器 |

## 8. 新手避坑清单（写镜头时）

AI 视频模型有固定的弱点，**在文字阶段避开它们比渲染后返工便宜得多**。Board 的 **Lint** 会把这类问题标成 `fragile.*`。

- ✅ **一个节拍只做一件事**，"开始状态 → 一个动作 → 结束状态"。
- ✅ **一个镜头只用一种运镜**；不想动就选 `static`。
- ✅ **用画面方向写**：写"向画面左侧走"，不要写"向东走"。
- ✅ **数量写数字**："一个黄色信封"。
- ✅ **每个动作写出原因**："风吹起袋子，他的手没有碰到它"。
- ✅ **写要发生的事，不写不要发生的事**："画面中只有首帧里的两个人"优于"不要出现别人"。
- ✅ **反应要提前在首帧里**：要拍某人的反应，他得一开始就在画面里、面向镜头；或者单独给他一个插入镜头。
- ✅ **有画面才有声音**：每个可见动作配一个声音，没有来源的声音不要写。
- ❌ 尽量避免：人物交叉穿行、手里拿小物件、画面里可读的文字、镜子和倒影、一个镜头里光线变化、一个人同时做三件事、遮住脸的俯拍、人群。
- ❌ 一个镜头内最多 3 次切换；更多就拆成多个镜头。
- 💡 先把镜头切成"每段戏"（开场、发展、转折、收尾），再把每段切成 8–12 秒的镜头；不要一上来就"N 个 5 秒镜头"。

## 9. 术语表

| 术语 | 中文 | 说明 |
| --- | --- | --- |
| Project | 项目 | 一部片子 = 一个项目 |
| Brief | 简报 | 用大白话描述片子 |
| Look | 外观 | 全片统一的类型、色调、摄影机、镜头、布光、负面约束 |
| Style preset | 风格预设 | 16 种现成风格，一键填好 Look |
| Script | 剧本 | 第一道审批 |
| Element | 元素 | 角色 / 场景 / 道具，带参考图 |
| Fixed features | 固定特征 | 绝不能变的细节（左臂纹身、帽子） |
| Scene / Shot | 场景 / 镜头 | 一个镜头 5–15 秒，一次生成 |
| Shotlist | 分镜表 | 所有场景和镜头，第二道审批 |
| Beat | 节拍 | 镜头内的一段动作 |
| Link | 衔接 | 镜头和前面镜头怎么接（硬切、续接、正反打……） |
| Hero frame / End frame | 首帧 / 尾帧 | keyframe 模式下的起始 / 结束画面 |
| Take | 一次渲染结果 | 同一镜头可以有多条，选一条用 |
| Probe | 试水渲染 | 先渲染最容易翻车的 1–2 个镜头 |
| Lint | 分镜体检 | 自动检查节奏、缺失参数和高风险画面 |
| Sketch | 色块故事板 | 根据分镜自动生成的草图 |
| LoRA | 微调插件 | 加速 LoRA 让渲染只需 8 步；风格 LoRA 改变画风 |
| Finals / Regenerate 2K | 成片精修 | 把选中的 take 重新生成为 1080p/2K/4K |
| Timeline | 时间线 | 排序、裁剪、配乐、字幕、导出 |
| Export preset | 导出预设 | preview-480p / master-768p / master-upscaled / social-9x16 |
| MCP / Connector | 连接器 | 让 Claude / Grok 操作本网站的接口 |
| Spend envelope | 授权额度 | 允许 AI 在额度内免确认渲染 |
| Delegated approval | 委托审批 | 允许 AI 代你批准剧本/分镜（默认关） |
| Retro | 复盘 | 项目结束后的问题总结 |
